Contributing to ChemoraPy 🧪

Thanks for your interest in contributing to ChemoraPy!

ChemoraPy is an open-source project exploring chemistry through Python and computational methods.

How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Add your feature, improvement, calculation, or bug fix.
5. Test your code.
6. Commit your changes.
7. Push your branch.
8. Open a Pull Request.

What You Can Contribute

- New chemistry calculations
- Scientific algorithms
- Bug fixes
- Documentation
- Tests
- Examples
- Performance improvements
- Visualizations

Contribution Guidelines

Please keep contributions:

- Scientifically accurate
- Easy to understand
- Well documented
- Consistent with the existing code
- Focused on one improvement per Pull Request

Before Contributing

For large features, please open an Issue first so the idea can be discussed before implementation.

Thanks for helping make ChemoraPy better! ⚗️

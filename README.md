🧪 ChemoraPy

«Chemistry × Python × Computation»

ChemoraPy is a Python-based project for exploring chemistry and atomic science through computational methods.

The goal is to turn chemistry concepts and mathematical models into simple, understandable Python programs.

🔬 Current Topics

ChemoraPy currently explores concepts such as:

- ⚛️ Aufbau Principle
- 🔢 Electronic Configuration
- 🧮 Slater's Rules
- ⚡ Effective Nuclear Charge ("Zeff")
- 🔋 Ionisation Energy / Enthalpy
- 🧠 Quantum Numbers
- 📈 Periodic Trends

🛠️ Built With

- 🐍 Python
- 🔢 NumPy
- 📊 Matplotlib

🚀 Vision

ChemoraPy is being developed as a learning-oriented computational chemistry toolkit.

Future areas may include:

- Atomic & molecular calculations
- Chemical simulations
- Molecular modelling
- Computational physics
- Data visualization
- Numerical methods

🎯 Why ChemoraPy?

Chemistry becomes even more interesting when we can calculate, model, and simulate the concepts we learn.

ChemoraPy aims to connect:

Chemistry → Mathematics → Physics → Programming

🌱 Status

🚧 Currently under development

New computational chemistry concepts and programs will be added as the project grows.
